# Shopping Cart — сравнение цен в израильских сетях

Привет! Это учебный и портфолио-проект: ты составляешь **список покупок**, а приложение сравнивает цены в сетях вроде Шуферсаль, Йоханов, Ошер Ад и Рами Леви и подсказывает, **где купить весь список выгоднее**.

Сейчас здесь только **каркас** (пустые, но уже запускаемые фронт и бэк) и этот README. Полноценный импорт прайсов и базы данных появятся на следующих шагах.

---

## Что уже лежит в репозитории

| Путь | Зачем |
|------|--------|
| `frontend/` | Интерфейс на **React + TypeScript** (сборщик **Vite**) |
| `backend/` | API на **Python FastAPI** |
| `docs/architecture.md` | Как устроены слои приложения (кратко) |
| `index.html`, `style.css`, `pictures/` | Твоё **портфолио** (старый статический сайт) — мы его не трогаем |
| `.gitignore` | Список файлов, которые Git не коммитит (venv, node_modules и т.д.) |

**Почему две папки frontend и backend?**  
Фронт — то, что видит пользователь в браузере. Бэк — сервер, который отдаёт данные по HTTP. Так делают почти все современные веб-приложения; на собеседовании это звучит как «разделение клиента и API».

## Запуск бэкенда (FastAPI)

Открой терминал и выполни **по шагам**.

### 1. Перейти в папку backend

```bash
cd backend
```

`cd` = *change directory* — «перейти в папку».

### 2. Создать виртуальное окружение Python

```bash
python3 -m venv .venv
```

**Что это значит?**  
`venv` — отдельная «песочница» для библиотек проекта. Так пакеты Shopping Cart не смешаются с другими Python-проектами на компьютере.  
Папка `.venv` появится внутри `backend/` (её Git игнорирует — это нормально).

На Ubuntu/Debian, если команда ругается на `ensurepip`, один раз поставь пакет системы:

```bash
sudo apt install python3.12-venv
```

(версия `3.12` может отличаться — смотри подсказку в ошибке).

### 3. Активировать окружение

```bash
source .venv/bin/activate
```

После этого в начале строки терминала обычно появляется `(.venv)`.  
Значит, дальнейшие `pip` и `python` работают **внутри** песочницы.

На Windows (PowerShell) активация другая: `.venv\Scripts\Activate.ps1`.

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

`pip` скачивает библиотеки из списка `requirements.txt` (сейчас это FastAPI и uvicorn).

### 5. Запустить API

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

| Часть команды | Простыми словами |
|---------------|------------------|
| `uvicorn` | Программа, которая поднимает веб-сервер для FastAPI |
| `app.main:app` | Файл `app/main.py`, объект `app` внутри него |
| `--reload` | При сохранении кода сервер сам перезапустится |
| `--host 127.0.0.1` | Слушать только этот компьютер (безопасно для учёбы) |
| `--port 8000` | Адрес будет `http://127.0.0.1:8000` |

Проверка: открой в браузере  
[http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)  
Должно быть что-то вроде `{"status":"ok"}`.

Документация API (автоматическая): [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

Остановить сервер: в терминале нажми `Ctrl+C`.

## Запуск фронтенда (React + Vite)

Открой **второй** терминал в VS Code (**Terminal → New Terminal**), чтобы бэкенд продолжал работать в первом.

### 1. Перейти в frontend

```bash
cd frontend
```

(Если ты ещё в `backend/`, сначала `cd ..`, потом `cd frontend`.)

### 2. Установить зависимости Node

```bash
npm install
```

`npm` читает `package.json` и кладёт пакеты в папку `node_modules/` (большая, в Git не коммитится).

### 3. Запустить Vite

```bash
npm run dev
```

В терминале появится адрес, обычно **http://localhost:5173**. Открой его в браузере.  
Должна быть страница: **«Сравнение цен на продукты — скоро»**.

Остановить: снова `Ctrl+C`.

## Быстрый чеклист «всё работает»

1. VS Code открыт на корне репозитория.
2. Терминал 1: `cd backend` → venv → `pip install` → `uvicorn ...` → `/health` отвечает `ok`.
3. Терминал 2: `cd frontend` → `npm install` → `npm run dev` → страница на русском.
4. Портфолио в корне (`index.html`) по-прежнему на месте — его можно открыть отдельно, это не часть приложения Shopping Cart.
